🏥 Healthcare Data Analysis Dashboard

📌 Project Overview
This project analyzes healthcare-related data using Microsoft Power BI. The objective is to explore healthcare datasets, identify useful insights, and present the findings through interactive visualizations and dashboards.

🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- Data Cleaning
- Data Visualization
- Data Analysis

📂 Project Structure

- `Dataset/` – Contains the Excel source datasets.
- `PowerBI/` – Contains the Power BI dashboard file.
- `Images/` – Contains dashboard screenshots.
- `Documentation/` – Contains project documentation.

📊 Dashboard Preview

Dashboard screenshots will be available in the Images folder.

📁 Dataset
This project uses multiple Excel files as source data. The datasets are used for data preparation, cleaning, transformation, analysis, and visualization in Power BI.

📈 Key Objectives
- Analyze healthcare-related data.
- Explore patterns and trends.
- Create interactive visualizations.
- Develop a user-friendly dashboard.
- Present data-driven insights.

🚀 How to Use
1. Download or clone this repository.
2. Open the PowerBI folder.
3. Open the `.pbix` file using Power BI Desktop.
4. If necessary, update the Excel source file paths.
5. Refresh the data.
6. Explore the interactive dashboard.
